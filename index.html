🛠 Personal Tools

A collection of lightweight browser-based tools built with pure HTML and JavaScript. All tools run locally in your browser without requiring a server or installation (except video conversion, which uses FFmpeg).

  • 💰 Stock Fee Calculator Calculate stock purchase costs, transaction fees, and remaining balance.
  • 🖼 Image Resizer Resize one or multiple images directly in your browser.
  • 🎬 Video Convert Convert, compress, trim, and preprocess videos using FFmpeg.
  • 📸 Extract Frame Extract one or multiple image frames from a video.
  • 🎤 Subtitle Player Display presentation subtitles from TXT scripts with synchronized highlighting and optional text-to-speech.
  • 🗣 Rehearse Practice presentations with live speech recognition, transcript, timing, and speaking statistics.
  • 👤 Resume Personal resume and technical portfolio.

Features

  • Pure HTML + JavaScript
  • No installation required
  • Runs entirely in the browser
  • No server required (except FFmpeg for video conversion)
  • Hosted with GitHub Pages
