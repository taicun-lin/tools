Personal Tools

This repository contains a collection of small personal tools and utilities. More tools may be added in the future depending on needs.

Available Tools

  • Fee Calculator - Simple stock purchase cost and remaining balance calculator.
  • Image Resizer - Resize single or multiple images directly in browser.
  • Resume - Personal resume and technical background.

Notes

  • Pure HTML + JavaScript
  • No installation required (Runs directly in browser)
  • Hosted with GitHub Pages
